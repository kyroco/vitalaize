VitalAIze is installed

VitalAIze is opening now.

If VitalAIze was already set up on this Mac

There is nothing to click. The install restarted your board or collector on the new version if it was running. The app puts right anything the older version left behind, and says what it did. Your settings and your database stay as they are. When it says The board is running (or The collector is running), you are done.

If this is the first time

  1. Pick what this Mac does, and check the answers VitalAIze filled in.
  2. On the last step, click Install and start the board (on a collector, Start the collector and pair). It starts, and starts again every time you log in.
  3. On your iPad, open the board's address in Safari (VitalAIze shows it), then tap Share and Add to Home Screen.

If VitalAIze did not open, find it in your Applications folder. Open it again any time to see the board, change the setup or remove it.
